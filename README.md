# Accessibility Quiz - HTML/CSS

This project is an accessibility quiz built using HTML and CSS. It is designed to help users practice basic accessibility concepts such as correct form labeling and element usage for better screen reader support.

## Features

- **HTML & CSS Questions**: The quiz includes basic questions about HTML and CSS.
- **Form Input Fields**: Users can input their information, including name, email, and birth date.
- **Accessibility**: The form and quiz elements are designed to be accessible, with proper labels, fieldsets, and roles.
- **Responsive Design**: The project is styled using CSS to ensure it looks great on various screen sizes.
- **Smooth Scroll**: The project ensures smooth scrolling behavior unless the user prefers reduced motion.
- **Custom Styles**: The quiz is visually enhanced with a modern layout and color scheme, focusing on readability and accessibility.

## How to Use

1. Clone the repository to your local machine.
   
   ```bash
   git clone https://github.com/your-username/accessibility-quiz.git
   ```

2. Open `index.html` in your browser.

3. Fill in the form with your information and answer the quiz questions.

4. Click "Send" to submit your responses.

## Files

- `index.html`: The main HTML file containing the structure of the quiz and form.
- `styles.css`: The stylesheet that styles the HTML elements.

## CSS Features

- **Responsive Design**: The layout adapts to different screen sizes, ensuring a smooth user experience.
- **Custom Fonts and Colors**: The design uses a mix of colors like #022e0238 for the background and #f1be32 for the header to create a clean, professional look.
- **Smooth Scrolling**: The `scroll-behavior: smooth;` property is applied for better navigation.
- **Interactive Elements**: Links, buttons, and navigation items have hover effects for a better user experience.
- **Accessible Forms**: Form inputs and labels are styled for clear interaction, with focus on accessibility.
- **Focus on Readability**: The font-family is set to Helvetica for general text and Verdana/Tahoma for headings to ensure legibility.

## Accessibility Features

- **Proper Use of Labels**: Every form field has an associated label, ensuring they are accessible to screen readers.
- **Fieldsets and Legends**: The form is grouped with fieldsets and legends for better context, especially for questions.
- **ARIA Roles**: ARIA roles and landmarks are used to enhance accessibility for users relying on assistive technologies.
